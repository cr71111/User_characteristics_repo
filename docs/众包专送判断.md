众包骑手 vs 专送骑手：特征对比与GPS数据判别方法

一、两类骑手的核心特征对比
维度   专送骑手   众包骑手
身份关系   隶属于配送商/代理商，类"正式员工"   自由注册，兼职/灵活用工

工作时间   固定排班（10-12h），午晚高峰必须在线，需参加早会（如9:30-10:30）   完全自由，想上线就上线，想下线就下线

接单方式   系统自动派单，根据所在区域就近分配   需要手动抢单或等系统指派，可自选订单

活动范围   绑定固定站点/区域，配送范围相对集中   跨区域跑单，可能从城东跑到城西

订单类型   大连锁商家为主（如麦当劳等），配送费较高   小店、巷子里的商家为主，常接"烂单"（超远、超重、爬楼）

管理约束   严格考勤、工服头盔、微笑行动检查   几乎无管理约束

出勤规律   恶劣天气必须上线，否则罚款   恶劣天气可自主选择

日单量   稳定但有上限（如日均21单保底）   波动大，靠手速和策略，勤快的可跑30+单

二、基于GPS/骑行数据的判别方法

如果你手上有骑手的 GPS轨迹数据 和 骑行数据，可以从以下几个维度构建特征来区分：

🔹 1. 时间维度特征（最强区分力）
特征   专送   众包
每日在线时长   长且稳定（10-12h）   短且波动大（2-8h不等）

上线/下线时间   规律性强，早会时间（9:30-10:30）有聚集   随机，无规律

午高峰在线率   几乎100%   不固定

晚高峰在线率   几乎100%   不固定

恶劣天气出勤   高（强制）   低（自愿）

工作日/周末差异   差异小（排班制）   差异大（自由选择）

可提取的特征指标：
日均在线时长 & 标准差
上线时间的熵值（衡量规律性，专送熵低、众包熵高）
午/晚高峰在线比例
连续在线天数
每周工作天数

🔹 2. 空间维度特征（核心区分力）
特征   专送   众包
活动范围   以站点为中心的小半径区域   大范围跨区域移动

轨迹覆盖面积   小且集中   大且分散

常驻点   有明显固定的"据点"（站点）   无固定据点，或多个据点

商家类型   集中在大连锁/商圈   分散在各种类型商家

配送距离   短且稳定   长且波动大

可提取的特征指标：
GPS轨迹的凸包面积（Convex Hull Area）或标准差椭圆
轨迹点的DBSCAN聚类数量和分散度
每日活动热力图的集中度
取餐点/送餐点的空间熵
最远配送距离 & 平均配送距离
每日不同区域间的跨区域转移次数

🔹 3. 骑行行为特征
特征   专送   众包
骑行速度   较稳定，路线熟悉   波动大，可能走生路

停留模式   取餐/送餐停留规律   有较多"等待抢单"的静止时间

路线重复度   高（固定区域）   低（跑不同地方）

并单行为   系统拼单，顺路性强   可能手动接多方向单，路线曲折

可提取的特征指标：
平均速度 & 速度方差
非取餐/送餐点的静止时长占比（众包等待抢单时间长）
路线的曲折系数（实际路程/直线距离）
相邻两单的方向变化角（专送顺路、众包可能折返）
单均骑行距离 & 方差

🔹 4. 订单节奏特征
特征   专送   众包
接单间隔   短且均匀（系统自动派单）   长且不均匀（需抢单）

单量日间分布   均匀、持续   脉冲式，有"空窗期"

同时携带单数   多单并行（系统拼单）   通常1-2单

可提取的特征指标：
相邻订单的时间间隔均值 & 变异系数
每小时单量的峰度
同时进行的订单轨迹交叉/并行度

三、建模建议

特征工程汇总（推荐Top 15特征）

features = {
    # 时间特征
    "avg_daily_online_hours": ...,       # 日均在线时长
    "online_hours_std": ...,             # 在线时长标准差
    "login_time_entropy": ...,           # 上线时间熵
    "lunch_peak_ratio": ...,             # 午高峰在线比
    "dinner_peak_ratio": ...,            # 晚高峰在线比
    "weekly_work_days": ...,             # 周工作天数
    
    # 空间特征
    "trajectory_convex_hull_area": ...,  # 轨迹凸包面积
    "poi_spatial_entropy": ...,          # 取送餐点空间熵
    "avg_delivery_distance": ...,        # 平均配送距离
    "delivery_distance_std": ...,        # 配送距离标准差
    "cluster_count": ...,                # 轨迹聚类数
    
    # 行为特征
    "avg_speed": ...,                    # 平均速度
    "idle_ratio": ...,                   # 静止时长占比
    "route_detour_ratio": ...,           # 路线曲折系数
    "order_interval_cv": ...,            # 接单间隔变异系数
}

推荐模型
方案   说明
规则引擎（快速版）   在线时长 > 8h 且 凸包面积 < 阈值 → 专送；否则 → 众包。准确率约 75-80%

随机森林/XGBoost   用上述特征训练二分类模型，准确率可达 90%+

轨迹序列模型（LSTM/Transformer）   直接将GPS轨迹序列输入模型，端到端学习时空模式，准确率最高但复杂度高

快速判断的经验法则

如果你只有少量数据，用这两条规则就能区分大部分骑手：
每天在线时间是否固定且超过8小时？ → 是则大概率专送
活动轨迹是否集中在一个小区域（< 5km²）？ → 是则大概率专送
